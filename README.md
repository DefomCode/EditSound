# EditSound
EditSound — self-hosted веб-приложение для хранения, каталогизации, поиска, прослушивания и скачивания аудиоресурсов, используемых при создании видео и другого контента.  По концепции напоминает Epidemic Sound, но каждый пользователь самостоятельно разворачивает собственную библиотеку и загружает в неё свои аудиофайлы.
